# Sysmon Endpoint Monitoring Lab

## Objective
Deploy Sysmon on a Windows endpoint to capture system and network telemetry and analyze suspicious activity using Windows Event Viewer.

## Environment
Host Machine: Windows PC  
Virtualization: VirtualBox  
Victim Machine: Windows 11 VM  

## Tools Used
Sysmon  
Windows Event Viewer  
PowerShell  

## Lab Setup
1. Installed Sysmon on the Windows VM.
2. Applied the SwiftOnSecurity Sysmon configuration.
3. Generated outbound network traffic using PowerShell.
4. Investigated captured telemetry using Event Viewer.

## Attack Simulation
Executed the following command to generate outbound network traffic:

curl http://example.com

This simulates a process making an external network connection similar to malware communicating with a command-and-control server.

## Detection Method
Navigated to the following log location in Event Viewer:

Applications and Services Logs → Microsoft → Windows → Sysmon → Operational

Focused on Event ID 3 which records network connections.

## Findings
Sysmon successfully captured network connection telemetry generated by the curl command.

Relevant Event:
Event ID 3 – Network Connection

Key Observations:
Process: powershell.exe  
Destination IP detected  
Destination Port detected  
Network activity successfully logged by Sysmon
